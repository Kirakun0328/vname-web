# ぶいネーム

VTuber・AIVTuberの名前を入力して、名前・読み・英字表記の重複候補を調べるツールです。

## ツールを開く

[ぶいネームを開く](https://kirakun0328.github.io/vname-web/)


## 使い方

名前を入力して「名前を調べる」を押すだけ。検索はブラウザ内で行います。入力内容は外部へ送信しません。

## 辞書について

初回拡充時点24,472レコード。AIVナビ連携後は24,603レコード（2026-09-07時点）。最新件数はサイト上に表示します。2026-09-07収集の既存辞書を使用しています。個人確認済みの人数ではなく、グループやチャンネルも含まれる可能性があります。過去の機械変換データは残っていますが、画面・検索では出典のない読みと英字を使いません。一致なしは名前の未使用を保証しません。

出典： [ユーザーローカル](https://virtual-youtuber.userlocal.jp/document/ranking)・[VTuber Database](https://vdb.vtbs.moe/)・[VTuber Post](https://vtuber-post.com/ranking_index.html)。項目抽出・名寄せ・機械変換を実施したデータです。一部ページは取得できていません。追加データは毎日自動更新します。

このリポジトリは公開画面用です。JavaScriptと辞書は閲覧・取得できます。検索結果はテキストとして表示し、CSPで外部接続とインラインスクリプトを制限しています。安全性を保証するものではありません。

## 読みの補正

`readings.js` の完全な名前単位の補正を、機械変換した読み・英字より優先します。空白の有無と全角・半角の違いを吸収し、姓だけを他の人へ置換することはありません。癒色えも（いしきえも）を含む13名を個別補正しています。未確認の読みは「不明」と表示し、誤読で検索に一致しないようにしています。

補正出典：[ホロライブ公式タレント一覧](https://hololive.hololivepro.com/talents/)（2026-09-07確認）。

## 多言語・別名検索

画面は日本語・英語・中文（簡体字）・한국어に対応。右上で切り替え、選択は端末内に保存します。初回はブラウザの言語に合わせます。検索入力と結果・ページ位置は言語切り替え時に維持します。

`extra-data.js` は既存711レコードに845個の別名・別言語表記を追加し、ユーザーローカルの公開ランキング1〜10ページから206レコードを追加しています。取得日：2026-09-07。未確認の読み・英字は推測せず空欄（画面では「不明」）にしています。初期データでは収集元IDと名前による重複候補の除外を行っていました。拡充版の新規登録はYouTubeチャンネルIDと出典のアカウント対応で照合し、同名の別チャンネルを名前だけで統合しません。異なる収集元の同一人物を完全には照合できていません。人数ではなくレコード数です。

## 自動更新

GitHub Actions が毎日日本時間6:17ごろに更新します。VTuber Databaseで既存レコードの別名を補完し、VTuber Postは小規模チャンネル側から1日90ページずつ、全ランキングページを順番に巡回します。登録者数の下限はありません。取得に失敗したページは後日再試行します。連続した取得失敗時は収集を早めに中断し、検証できたページを保存して次回再開します。GitHub側の都合で開始が遅れる場合があります。既存データと個別の読み補正を保持します。全員を毎日確認するものではありません。ユーザーローカル由来の既存データは維持し、名前の類似だけによる新規登録・除外は行いません。

取得失敗、形式変更、異常な件数増加時は更新を中止し、公開済みの辞書を維持します。Actions の「Update dictionary and publish」→「Run workflow」で手動実行も可能です。追加APIキーは不要です。公開リポジトリの定期実行は60日間リポジトリの活動がない場合にGitHub側で無効になることがあるため、停止時はActionsから再有効化してください。

## 読みの取得と優先順位

1. 出典付きの個別補正（本人・所属先の確認済み情報）
2. にじさんじ公式プロフィールの `ruby` フィールド
3. VTuber Postのプロフィール説明文にある、対象者のフルネームと読みを伴う自己紹介（例：名前（よみ）と申します）

名前の漢字から読みを推測したり、ローマ字から日本語の読みを逆算したりしません。括弧内がニックネームの可能性があるため、単なる括弧書きだけでは採用しません。出典URLを保存し、画面から確認できます。情報源の記載自体が正しいことを保証するものではありません。

毎日の更新では未確認・確認日が古いものから、公式プロフィール最大20件、VTuber Postプロフィール最大30件を順次確認します。全レコードを即時確認するものではありません。取得失敗時・明記がない場合は既存の出典付きの読みを保持し、個別補正は常に最優先します。

癒色えもの出典：[本人の自己紹介](https://note.com/ishiki_emo/n/n86e46e0ba925)。

## VTuber / AIVTuberタグ

AIVTuberも登録対象です。[毛玉雀のAIVナビ](https://aiv.nyagsicapp.com/characters)の公開キャラクター一覧を毎日の更新で取得します。YouTubeチャンネルIDと既存の収集元IDで照合し、既存レコードにAIVTuberタグと出典を追加、未収録の項目は新規登録します。同名という理由だけでは統合しません。AIVナビに明記された `name_kana` も、既存の出典付きの読みを上書きせず取得します。

AIVTuberタグがないレコードは広義のVTuberとして表示します。AI不使用を調査・確認したという意味ではありません。タグを押すと掲載元を確認できます。AIVナビ取得失敗時は既存のタグ・読み・登録を維持します。

画面下部にGitHubと[開発者のX](https://x.com/Kiratchi0328)へのリンクがあります。

## 掲載対象と小規模層への拡充

掲載対象は、実際にVTuber／AIVTuberとして活動を開始している方です。活動開始前の「VTuber準備中」の方は対象外です。サイト上にも日本語・英語・中国語・韓国語で明記しています。現在活動を休止しているかどうかとは別の基準です。

新しいVTuber Postの登録には、VTuberディレクトリへの掲載と動画総再生回数が正であることを最低限の活動の手掛かりとし、準備中と明記された名前・再生実績不明の項目は追加しません。登録者数だけでは活動開始と判定しません。これは個々の初配信を視聴した証明ではありません。VDBのアカウント掲載だけで未確認の新規項目を追加しません。AIVナビの新規項目は活動中・配信中などの記載があるものを追加します。既存レコードの活動状況の全件確認は未完了で、元情報の古さ・漏れによる判定の限界があります。準備中の表示は取得元の更新で活動を確認できれば再掲載できます。

`python scripts/update_dictionary.py --full` でVTuber Postの全ページを巡回できます。POSTフォームによるページ送り、実際の順位・ページ件数・チャンネルIDの検証を行い、誤って先頭ページを何度も集めることを防ぎます。`scripts/collection-report.json` に取得ページ数・失敗ページ・新規件数・登録者1,000人未満の新規件数を保存します。失敗時は既存データを維持します。出典URLを検索結果から開けます。

「6万人以上」はVTuber全体に関する推計と、本ツールの収録件数を混同しないよう扱います。全VTuberの網羅や、6万人分の登録を保証するものではありません。

## VSTATSの個人勢一覧

[VSTATSの個人勢一覧](https://www.vstats.jp/brands/1)も収集元に追加しています。YouTubeチャンネルIDで既存レコードと照合し、プロフィールのチャンネルID一致・総再生回数を確認できた項目を追加します。準備中の表示と活動実績を確認できない項目は新規追加しません。毎日の更新では、未収録の小規模チャンネルを優先して最大30プロフィールを確認します。名前の読みはこの情報から推測しません。

## 小規模な活動者のプロフィール

[liverfun.jpのVTuber名鑑](https://www.liverfun.jp/vtuber/)から、合計SNSフォロワーが1,000未満のプロフィールを1日30件ずつ巡回します。この値はYouTube登録者数ではありません。本人プロフィールのVTuberとしての記載と、配信中・配信しています等の活動の明記を両方確認します。単なるVTuberファン、準備中、年が不明なデビュー予告、活動予定だけの項目は追加しません。公開プロフィール上の記載による確認であり、実際の配信映像を確認した保証ではありません。

掲載元のプロフィールURLと公開活動アカウントを保持し、同一アカウントは既存項目にまとめます。名前しか一致しない場合は、この情報源から新たな項目や人物同一性を推測しません。読みは推測しません。プロフィール本文・画像・連絡先は保存しません。
