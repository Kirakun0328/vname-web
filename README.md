# ぶいネーム

VTuberの名前を入力して、名前・読み・英字表記の重複候補を調べるツールです。

## ツールを開く

[ぶいネームを開く](https://kirakun0328.github.io/vname-web/)


## 使い方

名前を入力して「名前を調べる」を押すだけ。検索はブラウザ内で行います。入力内容は外部へ送信しません。

## 辞書について

24,266レコード。2026-09-07収集の既存辞書を使用しています。個人確認済みの人数ではなく、グループやチャンネルも含まれる可能性があります。読みと英字には機械変換が含まれます。一致なしは名前の未使用を保証しません。

出典： [VTuber Database](https://vdb.vtbs.moe/)・[VTuber Post](https://vtuber-post.com/ranking_index.html)。項目抽出・名寄せ・機械変換を実施したデータです。一部ページは取得できていません。自動収集・定期更新は未設定です。

このリポジトリは公開画面用です。JavaScriptと辞書は閲覧・取得できます。検索結果はテキストとして表示し、CSPで外部接続とインラインスクリプトを制限しています。安全性を保証するものではありません。

## 読みの補正

`readings.js` の完全な名前単位の補正を、機械変換した読み・英字より優先します。空白の有無と全角・半角の違いを吸収し、姓だけを他の人へ置換することはありません。兎田ぺこらなど12名を補正済みです。未確認の名前は参考情報として表示します。

補正出典：[ホロライブ公式タレント一覧](https://hololive.hololivepro.com/talents/)（2026-09-07確認）。
