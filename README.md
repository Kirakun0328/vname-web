# ぶいネーム

VTuber・AIVTuber・Vライバーの活動名を、名前・読み・別名・活動プラットフォームから検索できる名前チェックツールです。

- 公開サイト: https://kirakun0328.github.io/vname-web/
- 掲載対象: 実際に活動を開始しているVTuber / AIVTuber / Vライバー
- VTuber準備中・Vライバー準備中は原則として掲載対象外
- 検索結果に一致がなくても、その名前が未使用であることを保証するものではありません

## 現在のデータ運用

2026-09-09から、一般VTuber/Vライバーについて、第三者の名鑑・ランキング・データベースや事務所ロスターをそのまま大量に取り込み、公開辞書へ自動追加する運用を停止しています。

新しい一般VTuber/Vライバーの掲載・修正は、原則として次のいずれかで行います。

1. 本人または利用者からの掲載・修正申請
2. 本人の公開プロフィールを個別確認
3. 配信プラットフォームの個別プロフィールを個別確認
4. 所属事務所・運営元の個別タレントページを個別確認

一覧ページや外部DBは、候補を見つけるための手掛かりとして参照する場合がありますが、その一覧自体を転載するためには使用しません。

保存する情報は、活動名、読み、公開プロフィールURL、活動媒体、公開アカウントIDなど、名前検索に必要な事実情報を中心とします。紹介文、プロフィール本文、画像、ランキング記事本文などは原則として転載しません。

AIVTuber関連は別の収集・確認方針で扱っています。

詳しくは [DATA_SOURCES.md](DATA_SOURCES.md) を参照してください。

## 既存データについて

現在の辞書には、2026-09-08以前に公開名簿・公開スナップショット等を参考に作成した既存レコードが含まれています。これらは新規の一括取り込みを止めたうえで、本人・公式の個別ページを使った再確認を順次進めています。

既存レコードの出典履歴は、誤った出典の付け替えを避けるため可能な範囲で保持しています。別の公式ページを後から確認したからといって、過去の取得元に関する利用条件が自動的に解決するという扱いにはしていません。

このリポジトリのデータファイルについて、第三者由来データを含めて一律に自由再配布できるというライセンスは付与していません。各情報源・各権利者の権利はそれぞれに帰属します。

## 重要: 静的サイトのデータ配信

現在のGitHub Pages版はブラウザ内で検索する静的サイトのため、検索に必要な辞書データをクライアントへ配信する構成です。

そのため、データファイル自体の配布を完全に避けるには、将来的に検索処理をサーバー側APIへ移し、ブラウザには検索結果だけ返す構成への変更が必要です。暗号化・難読化だけでデータ取得を防げるとは考えていません。

## 読み方

読みは次の順で扱います。

1. 本人・公式・申請で明示された読み
2. 個別に確認したプロフィール上の読み
3. 推定読み（推定であることを画面上に明記）

漢字名の読みを確定情報として勝手に決めない方針です。修正申請で本人・公式の読みが示された場合は、その情報を優先します。

## 掲載・修正申請

公開サイトの「掲載・読み方の修正」から申請できます。

必要な情報:

- 活動名
- 正しい読み
- YouTube / Twitch / IRIAM / REALITY / TikTok / 17LIVE / SHOWROOM 等の公開活動URL

申請内容は確認してから反映します。自動承認ではありません。

## 自動処理

GitHub Actionsでは、一般VTuber/Vライバーの外部ロスターを巡回して大量追加する処理は実行しません。

現在の定期処理は主に次の用途です。

- 個別にreviewed扱いにした追加・修正の反映
- 既存レコードの個別公式プロフィール再確認
- 読み推定キューの更新
- JavaScript / テストの検証
- GitHub Pagesの公開

## セキュリティ・プライバシー

名前検索はブラウザ内で行います。検索欄へ入力した文字列を検索APIへ送信する構成ではありません。

AI名前相談はローカル実行を前提とした試験機能です。モデル本体や実行用ファイルは外部から取得します。
